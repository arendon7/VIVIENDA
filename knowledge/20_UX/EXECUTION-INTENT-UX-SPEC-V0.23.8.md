# EXECUTION INTENT UX SPEC — V0.23.8

Status: implementation contract

## Product intent

After the user has reviewed **Mi Decisión**, the product must ask one more explicit question before showing the action plan:

> **¿Cómo quieres avanzar?**

This prevents the UI from silently deciding whether a route is self-managed, assisted or legal/professional.

## Canonical sequence

`Radar → Mi Decisión → elegir cómo avanzar → Plan de acción → expediente local de demostración`

The chooser is local and ephemeral.

## No implicit default

No execution mode is preselected.

Opening the next step from Mi Decisión displays the chooser first. The Case Plan is not rendered until the user selects one available option.

## Consumer-facing options

### Prepararlo por mi cuenta

Use when self preparation is supported.

Copy must explain:

- the product organizes steps/documents;
- the user remains responsible for external acts;
- this version does not send or execute instructions before a bank or third party.

### Revisarlo con acompañamiento

Use only for R7 while the existing Auditoría Hipotecaria assisted blueprint is available.

Copy must explain:

- this is a demonstration of the assisted modality;
- choosing it does not contract the service;
- there is no payment or final quoted price;
- real evidence persistence would require data authorization;
- a real service would require separate acceptance.

### Preparar revisión profesional

Use when ordinary self-management is not appropriate and professional review governs the next step.

Copy must explain:

- this prepares information for review;
- no lawyer is retained by selecting it;
- no power is granted;
- no legal strategy is generated by the choice itself.

## R7 experience

R7 is the primary UX case for this slice.

When R7 governs, the chooser must display:

1. `Prepararlo por mi cuenta`;
2. `Revisarlo con acompañamiento`.

It must not replace both with a generic legal path merely because the route later requires professional review.

If the user chooses accompaniment:

- the plan visibly shows `Acompañamiento`;
- the demo Case origin uses the assisted mode;
- `Servicio aceptado` begins as `No`;
- a separate safe demo action may simulate service acceptance;
- authority/power remain separate.

## R10 experience

When R10 governs:

- show only `Preparar revisión profesional`;
- do not show ordinary self preparation;
- do not show the assisted R7 audit option;
- do not expose a service-acceptance action in the legal demo merely because review is required.

## Plan header

After a mode is selected, Case Plan shows the chosen mode as a visible chip:

- `Autogestión`;
- `Acompañamiento`;
- `Revisión profesional`.

The plan also states that the selection remains local and does not create a case, contract, authorization or external action.

## Changing mode

The user may choose `Cambiar forma de avanzar` from an open plan.

This returns to the chooser and clears the local execution selection and local timeline view.

It does not change the selected route or Decision Basis.

## Revalidation interaction

When V0.23.6 detects a material decision change:

- the plan closes;
- the chooser/selected mode disappears;
- the user must review the changed Decision Brief;
- after accepting the current basis, choosing how to proceed is required again.

No stale mode survives a governing-route change such as R1 → R10.

## Case history demo

The history must display the explicitly selected mode in consumer language.

Internal values such as `self_service`, `assisted`, `legal` remain data attributes/domain values and must not appear as visible text.

The initial demo history remains simulated and non-persistent.

## Consumer-language firewall

Visible copy must avoid internal/engineering vocabulary already prohibited by the product firewall, including raw track codes and English implementation terms.

Use Spanish labels:

- Autogestión;
- Acompañamiento;
- Revisión profesional;
- vista local;
- demostración.

## Accessibility

The chooser is a semantic section with a visible heading.

Every available execution option is represented by a real button whose accessible name is the option title.

Availability is not communicated by color alone.

## Acceptance criteria

- chooser appears before Case Plan;
- no option is automatically selected;
- R1/R2 show self preparation only;
- R7 shows self preparation and accompaniment;
- R10 shows professional review only;
- selected mode appears in the plan header;
- changing mode returns to chooser;
- assisted R7 timeline shows accompaniment and starts with service not accepted;
- legal timeline has no service-acceptance control by default;
- revalidation clears the chooser/plan state;
- consumer-language firewall remains green on desktop and mobile.
